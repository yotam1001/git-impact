Why not git diff?

git diff compares the index and working tree. git diff --cached (or --staged) compares HEAD and the index. Supply the target commit to compare against it. These are useful native tools; Git Impact combines the proposed reset’s effects on staging, disk, obstructions, and history in one report.

In this synthetic example, output was a committed file at the target but is now an untracked directory. Hard reset replaces it, including output/local-export.csv. The diffs show the target file but omit the untracked CSV’s content. notes.txt is also untracked and stays unchanged.
